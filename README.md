## About

I work across the stack — from infrastructure and deployment automation to the
applications that run on it. My work centers on **Kubernetes and GitOps-based
delivery**, **CI/CD tooling**, and **developer/product automation**, with a
strong bias toward building tools that make systems easier to operate.

- **Cloud & Kubernetes** — Helm charts, observability stacks, reproducible environments
- **Delivery automation** — GitOps workflows, release pipelines, GitHub Actions
- **Developer tooling** — browser automation, agent tooling, internal utilities
- **Full-stack** — TypeScript, Python and modern frontends (Vue/Nuxt, React)
