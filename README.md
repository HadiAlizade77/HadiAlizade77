## About

Senior software engineer with **9+ years** architecting and scaling SaaS platforms
for coworking, facility management and logistics — serving **400,000+ users**. I lead
teams of 5–20 engineers and build **microservice, event-driven systems on AWS and
Kubernetes**, with a strong bias toward DevOps automation, observability and
systems that are easy to operate.

- **Backend** — Node.js/NestJS, Python, PHP/Laravel · GraphQL & REST · Kafka, WebSockets, BullMQ
- **Cloud & DevOps** — AWS (RDS, S3, Lambda, MSK, ECS), Kubernetes, Docker, CI/CD, infrastructure as code
- **Data** — PostgreSQL, Neo4j, Redis, MongoDB — high-throughput paths at ~20 ms latency
- **Observability & quality** — OpenTelemetry, ELK, Sentry · Playwright/Cypress · clean architecture at team scale

## Selected impact

- Platform architecture serving **400,000+ users** across B2B SaaS products
- Deployment cycle cut from **1 week to 5 minutes** through automated CI/CD and release trains
- Monolith re-architected into **20 microservices** — 50% lower cloud cost, independent deploys
- **1M+ daily transactions** at ~20 ms average latency (GraphQL + Neo4j + Redis + Kafka)
- Led teams of **5–20 engineers**; mentored engineers into senior and lead roles
- Incident response time reduced by **50%** with OpenTelemetry + Sentry + ELK observability
